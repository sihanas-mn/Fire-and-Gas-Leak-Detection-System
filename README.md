# Fire-and-Gas-Leak-Detection-System

This project is for a **Fire and Gas Leak Detection System**.

## Purpose
Use this system to monitor an area for:
- Fire/smoke risk
- Gas leakage risk

When abnormal values are detected, the system should trigger alerts so action can be taken quickly.

## How to use this repository
1. **Clone the repository**
   ```bash
   git clone https://github.com/sihanas-mn/Fire-and-Gas-Leak-Detection-System.git
   cd Fire-and-Gas-Leak-Detection-System
   ```
2. **Open the project source code** in your preferred IDE or microcontroller development tool.
3. **Connect your sensors and controller hardware** according to your circuit design.
4. **Build and upload the code** to your board.
5. **Power the device and test** using safe test conditions (for example, controlled smoke/gas simulation tools).

## Recommended safety notes
- Do not test with dangerous gas concentration levels.
- Validate readings in a controlled environment before real deployment.
- Keep a manual safety backup (alarm/extinguisher/ventilation).
